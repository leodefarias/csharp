Salvar e carregar os dados em JSON

Dependência

Concluir todos os tickets obrigatórios.

Implementação solicitada

  1. Serializar recursos e reservas com System.Text.Json.
  2. Salvar os dados em arquivos JSON ao encerrar.
  3. Carregar os arquivos quando o programa iniciar.
  4. Tratar a primeira execução, quando os arquivos ainda não existem.

Critérios de aceite

  • Os arquivos são criados automaticamente.
  • Recursos e reservas reaparecem após reiniciar.
  • Arquivo inexistente não encerra o programa.
  • Os tickets obrigatórios continuam funcionando.

Validação

  1. Cadastre um recurso e uma reserva.
  2. Encerre a aplicação.
  3. Execute novamente.
  4. Confirme os dados pelas opções de listagem.
