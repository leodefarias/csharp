Tipos em C#

Tipos de valor

Guardam o próprio valor. Uma atribuição cria uma cópia independente.

int quantidade = 10;
decimal preco = 25.90m;
bool disponivel = true;
DateTime inicio = DateTime.Now;

Exemplos: estruturas (struct) e enumerações.

Tipos de referência

Guardam uma referência para um objeto. Duas variáveis podem apontar para o mesmo objeto.

string nome = "Sala 301";
Recurso recurso = new Recurso();
List<Recurso> recursos = new();

Exemplos: classes, interfaces, arrays e delegados.

Todos os tipos derivam de System.Object. Tipos de valor passam por System.ValueType; tipos de referência derivam diretamente ou indiretamente de object.

Classe, objeto e coleção

Classe

É a definição do tipo: determina quais dados e comportamentos seus objetos terão.

public class Recurso
{
    public int Id { get; set; }
    public string Nome { get; set; }
}
Objeto

É uma instância concreta da classe, com identidade e valores próprios.

var sala = new Recurso
{
    Id = 1,
    Nome = "Sala 301"
};
Coleção

Armazena vários objetos do mesmo tipo.

var recursos =
    new List<Recurso>();

recursos.Add(sala);
A classe é a definição; o objeto é uma ocorrência concreta criada com new.
