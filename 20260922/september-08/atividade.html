Dependência

Entity Framework Core

Registrar as entidades no DbContext

Dependência

Concluir LAB-002.

Registrar as duas entidades modeladas e configurar o relacionamento em um único passo.

Implementação solicitada

  1. Adicionar DbSet<Pedido> ao AppDbContext.
  2. Adicionar DbSet<ItemPedido> ao AppDbContext.
  3. Configurar Pedido.HasMany e ItemPedido.WithOne no OnModelCreating.
  4. Indicar ItemPedido.PedidoId como chave estrangeira.

Critérios de aceite

  • Os dois DbSet estão disponíveis no contexto.
  • O relacionamento é um para muitos.
  • Pedido é principal e ItemPedido é dependente.

Validação

modelBuilder.Entity<Pedido>()
    .HasMany(pedido => pedido.Itens)
    .WithOne(item => item.Pedido)
    .HasForeignKey(item => item.PedidoId);

Consulta

Gerar resumo agrupado

Dependência

Concluir LAB-012.

Produzir informação derivada, em vez de apenas devolver linhas da tabela.

Implementação solicitada

  1. Adicionar ObterResumoAsync ao IPedidoService e ao PedidoService.
  2. Criar GET /api/pedidos/resumo.
  3. Considerar somente pedidos ativos.
  4. Agrupar os pedidos por status.
  5. Calcular quantidade de pedidos e soma dos totais em cada grupo.
  6. Ordenar o resultado pelo status.

Critérios de aceite

  • O agrupamento é executado pela consulta do Entity Framework Core.
  • Cada item informa status, quantidade e valor total.
  • Pedidos inativos não participam do resumo.
  • A rota funciona quando não há pedidos.

Validação

var resumo = await db.Pedidos
    .Where(pedido => pedido.Ativo)
    .GroupBy(pedido => pedido.Status)
    .Select(grupo => new
    {
        Status = grupo.Key,
        Quantidade = grupo.Count(),
        ValorTotal = grupo.Sum(pedido => pedido.Total)
    })
    .ToListAsync();
