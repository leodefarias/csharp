Excluir não precisa apagar

Exclusão física
db.Produtos.Remove(produto);

O registro deixa de existir no banco e seu histórico pode ser perdido.

Exclusão lógica
produto.Ativo = false;

O registro permanece armazenado, mas deixa de aparecer nas consultas normais.

Nesta aula, DELETE representa uma ação de negócio: desativar o recurso.

Code-first em três movimentos

Modelo

Criamos as classes C# que representam entidades e relacionamentos.

Migração

O Entity Framework Core compara o modelo e gera a alteração do banco.

Banco

Aplicamos a migração no SQL Server LocalDB e consultamos os dados.

Nossa primeira entidade

public sealed class Produto
{
    public int Id { get; set; }
    public string Nome { get; set; } = string.Empty;
    public decimal Preco { get; set; }
    public int Estoque { get; set; }
    public bool Ativo { get; set; } = true;
}

A propriedade Id vira a chave primária por convenção.
